# TradePast web platform setup\n\nThe web experience adds a public landing page and Supabase email/password authentication around the existing React backtesting engine. Electron desktop builds bypass web authentication and remain local/offline.\n\n## Connect free authentication\n1. Create a Supabase project on its Free plan: https://supabase.com/dashboard\n2. Copy the Project URL and publishable/anon key from Project Settings → API.\n3. Set `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY` as deployment build environment variables (or in `.env.local` for local development).\n4. In Supabase Authentication → URL Configuration, set the deployed site URL and allowed redirect URLs.\n5. Configure email confirmation and the email provider before opening registration publicly.\n\nOnly the public anon/publishable key belongs in browser builds. Never expose a service-role key.\n\n## Scope of this first web foundation\n- Email/password sign-up, login, session restoration/refresh and logout use Supabase Auth.\n- The backtesting engine remains client-side. Saved sessions and drawings remain in the current browser profile; cloud sync and cross-device backups are not included yet.\n- The four-second “Advertising” toast is a placement marker only; it does not itself serve paid ads or generate revenue. A real ad network account, approved site and live ad units are required.\n- The ad-free purchase is a future billing integration; no payment is collected in this release.\n\n## Hosting and domain\nGitHub Pages can host the site on a free project URL. A custom domain such as `www.tradepast.com` must be registered/owned separately and its DNS configured by the domain owner. Supabase Free projects may pause after one week of inactivity, so it is appropriate for an initial pilot, not an uptime-guaranteed production service.\n
